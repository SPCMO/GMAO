📧 Notifications par mail (SMTP)

Stocké uniquement dans settings.json sur ce poste, jamais publié. Utilisé par le script quotidien scripts/verifier_alertes.py (voir Aide.html).

🔗 Relais mail (Google Apps Script) — recommandé

Le réseau SPCMO bloque le SMTP direct ci-dessus. Solution qui fonctionne : un petit script Google Apps Script (fichier apps_script/gmao_mail_relay.gs du dépôt) envoie le mail via Gmail côté serveur Google ; GMAO le contacte simplement en HTTPS, comme il le fait déjà pour GitHub. Voir Aide.html (onglet Paramétrage) pour les étapes de déploiement du script.

Doit correspondre exactement à TOKEN_SECRET dans le script Apps Script déployé.
